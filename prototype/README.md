# METHORICS — макет интерфейса (HTML/CSS/JS)

Кликабельный прототип боевой ИИ‑системы для правообладателей. Светлая тема,
графовый мотив, без внешних JS‑библиотек (работает офлайн; из сети тянутся
только веб‑шрифты). Соответствует разделам 6+ документа
«Methorics · боевая ИИ‑система для правообладателей».

## Как открыть
Откройте **`index.html`** в браузере — это точка входа. Дальше всё кликается:
выбор профиля → онбординг → консоль → симуляция. Состояние между экранами
передаётся через параметр URL (`?profile=…`, `?scn=…`), без localStorage.

## Карта экранов
1. **index.html** — запуск. Выбор профиля развёртывания A–E
   (локальный / локально‑гибридный / self‑hosted / TEE / SaaS‑демо).
   По умолчанию выбран **B** (рекомендованный розничный контур).
2. **onboarding.html** — мастер из 5 шагов: субъект → домен → активы →
   документы → уточнение. Справа в реальном времени растёт «прочность картины»
   и список «что уже знает система».
3. **workspace.html** — рабочая консоль из трёх зон: слева диалог с ассистентом,
   в центре карта прав (граница идентичности + Среда, узлы кликабельны),
   справа прочность, единые точки отказа и каталог из 11 шоковых сценариев.
   Выбор сценария подсвечивает затронутые узлы на карте.
4. **simulation.html** — прогон выбранного сценария: анимация расчёта → вердикт,
   метрики, дерево атаки (таймлайн), радар «до / после рекомендаций»,
   подсвеченные узлы, приоритизированные рекомендации и дисклеймер.

## Файлы
- `index.html`, `onboarding.html`, `workspace.html`, `simulation.html` — экраны
- `styles.css` — дизайн‑система (CSS‑переменные, компоненты)
- `methorics.js` — общий движок: логотип, иконки, профили, граф прав,
  каталог сценариев, движок симуляции, радар, навигация
- `logo.svg` — логотип (буква М в виде графа из узлов и связей)

Все ссылки между файлами — относительные по имени, поэтому пакет работает
из любой папки без сборки и сервера.

## Это макет
Данные, диалоги и результаты симуляций — демонстрационные (зашиты в `methorics.js`).
Прототип показывает облик и потоки интерфейса до начала разработки, а не рабочую логику.
